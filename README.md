# 🎵 Music Player

Luajtës muzikor në browser me playlist dhe kontrolle play/pause. Këngët dhe kopertinat ngarkohen nga lista e playlist-ës (kërkon internet); demo-ja hapet dhe punon pa file-e audio lokale.

## 🚀 Si ta hapësh

Hap `index.html` në browser (ose demo-n live më poshtë) dhe kliko butonin **play**. Këngët transmetohen nga interneti, ndaj lidhja kërkohet për audio; ndërfaqja dhe kontrollerët punojnë edhe pa audio.
